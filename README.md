# Tek Asfalt iOS Uygulaması

React Native ve Expo ile hazırlanmış gerçek iOS/Android uygulamasıdır.

## Yerel önizleme

1. Telefona Expo Go yükleyin.
2. Bu klasörde `pnpm start` çalıştırın.
3. Oluşan QR kodu iPhone kamerasıyla okutun.

## App Store paketi

Apple Developer hesabı bağlandıktan sonra `eas build --platform ios --profile production` komutuyla imzalı App Store paketi oluşturulur.

Bundle identifier: `com.tekasfalt.mobile`
